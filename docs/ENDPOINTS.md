# API Endpoints

Base URL when running locally:

```text
http://127.0.0.1:5000
```

## 1. GET /health

Checks whether the microservice is running.

Response:

```json
{
  "service": "AI Text Processing Microservice",
  "status": "healthy",
  "version": "1.0.0"
}
```

## 2. POST /analyze-text

Performs local computation. No external API is required.

Request:

```json
{
  "text": "Hello world. This is a test."
}
```

The endpoint returns:

- word count
- character count
- sentence count
- longest word
- estimated reading time

## 3. POST /translate

Uses Google Gemini as an external API.

Request:

```json
{
  "text": "Magandang umaga",
  "target_language": "English"
}
```

Response example:

```json
{
  "original_text": "Magandang umaga",
  "translated_text": "Good morning",
  "target_language": "English"
}
```

The exact translation can vary because it is generated by the AI service.

## 4. POST /batch-analyze

Analyzes multiple texts using `ThreadPoolExecutor`.

Request:

```json
{
  "texts": [
    "Hello world.",
    "Docker is useful.",
    "APIs connect applications."
  ]
}
```

Response:

```json
{
  "count": 3,
  "results": [
    {"text": "Hello world.", "word_count": 2},
    {"text": "Docker is useful.", "word_count": 3},
    {"text": "APIs connect applications.", "word_count": 3}
  ]
}
```

The real response also includes the other analysis fields.
